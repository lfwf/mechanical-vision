# 机械视界 · 互动式 3D 机械原理百科

这是“机械视界”的初始框架版本。当前已经完成一个可运行的外啮合直齿圆柱齿轮实验：

- 两个程序化生成的真实齿形 3D 齿轮；
- 鼠标旋转、缩放和平移视角；
- 主动轮与从动轮齿数可调；
- 输入转速与旋转方向可调；
- 从动轮转速、方向和传动比实时联动；
- 节圆、标签、网格显示控制；
- 点击齿轮查看部件说明；
- 数据驱动的知识目录，已预留后续机械实验入口；
- 响应式页面布局。

## 技术栈

- React 19 + TypeScript
- Vite 8
- Three.js
- React Three Fiber
- Drei
- Zustand

## 核心计算关系

理想外啮合齿轮副满足：

```text
n₁ × z₁ = -n₂ × z₂
```

其中：

- `n₁`：主动轮转速；
- `z₁`：主动轮齿数；
- `n₂`：从动轮转速；
- `z₂`：从动轮齿数；
- 负号表示旋转方向相反。

当前版本按理想刚性传动计算，不计齿侧间隙、变形、摩擦和效率损失。

## 后续扩展方式

增加新的实验时，建议按以下顺序：

1. 在 `src/data/catalog.ts` 注册实验；
2. 新建独立的实验状态与机械计算模块；
3. 新建 3D 场景组件；
4. 复用现有目录、顶部栏、控制区和信息面板布局；
5. 复杂设备改用 Blender 制作并导出 GLB，零件名称统一使用 `PART_*` 前缀；
6. 把教学内容拆到 `src/data`，不要写死在 3D 组件中。

下一批建议实现：齿轮齿条、行星齿轮、曲柄滑块、凸轮和离心泵。
