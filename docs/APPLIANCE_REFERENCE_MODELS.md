# 家用设备参考实机与拆装模型规范

## 为什么必须固定参考型号

“空调”和“洗衣机”不是单一结构。不同容量、地区版本、生产批次、驱动方案和功能配置会改变零件位置与拆装顺序。

因此本项目不再制作没有型号边界的通用外壳，而是先登记一个公开在售型号，再分开处理三类精度：

1. **已由官方资料确认的事实**：产品型号、外形尺寸、容量、官方功能、直驱或热泵等系统边界；
2. **可由工程原理确认的拓扑**：压缩—冷凝—节流—蒸发、水路、内外筒、悬挂和驱动关系；
3. **尚未获得原厂 CAD 或完整服务手册的细节**：紧固件数量、卡扣位置、专有管路尺寸、线束走向和维修扭矩。这些内容必须标记为简化，不能伪装成制造级模型。

## 空调参考实机

### Daikin Perfera FTXM35R + RXM35R

参考资料：Daikin Europe 官方 Perfera FTXM-R / RXM-R 产品目录 `ECPEN20-007`。

用于模型比例的公开数据：

- 室内机规格段：高 299 mm、宽 998 mm、深 292 mm；
- 室外机规格段：高 550 mm、宽 765 mm、深 285 mm；
- 产品属于一台室内机配一台室外机的分体式热泵系统；
- 产品资料明确描述宽幅导风板、过滤功能和室内外换热/送风能力。

模型包含：

- 室内机：前面板、过滤网、翅片换热器、贯流风轮、风机电机、接水盘、导风板、电控盒；
- 室外机：顶盖与前护网、折弯翅片换热器、轴流风扇、风机电机、压缩机、逆变电控盒、四通阀、电子膨胀阀；
- 制冷路径：压缩机 → 室外换热器 → 电子膨胀阀 → 室内换热器 → 压缩机。

当前模型属于 **L2 实机结构拓扑与装配关系级**。外壳比例有官方尺寸依据；内部零件用于表达正确的系统位置、遮挡和连接关系，不等同于 Daikin 原厂 CAD。

## 洗衣机参考实机

### LG WM4000HWA

参考资料：LG Electronics USA 官方产品页和官方支持页。

由官方资料确认的边界：

- 4.5 cu. ft. 前置式滚筒洗衣机；
- TurboWash 360、智能洗涤、蒸汽和钢化玻璃门等产品特征；
- 官方支持页将 `Direct Drive Motor` 和 `Stainless Steel Drum` 作为独立组件类别登记。

模型包含：

- 机壳层：顶盖、控制面板、前面板、钢化玻璃门；
- 进水与投放：多路进水阀、洗涤剂抽屉与分配器；
- 筒体与密封：门封波纹管、不锈钢内筒、悬挂外筒；
- 悬挂与减振：配重块、上部弹簧、下部减振器；
- 驱动：后置直驱转子和定子；
- 排水与控制：排水泵/过滤器和主控制板。

运行模式分为：

1. 进水与洗涤剂投放；
2. 低速正反转翻滚；
3. 排水泵排水；
4. 内筒高速脱水、外筒悬挂减振；
5. 逐件拆装。

当前模型属于 **L2 实机结构拓扑与运动关系级**。它不计算洗净指数、不平衡控制、轴承寿命、耗水量和减振器阻尼。

## 逐件拆装机制

每个可拆零件都必须有唯一 ID，并同时出现在：

- 三维场景的 `ExplodablePart`；
- 实验定义的 `partManuals`；
- 右侧零件目录；
- 自动结构检查。

用户可以：

- 点击三维零件选择；
- 在零件目录中选择；
- 单独拆下或装回当前零件；
- 全部展开；
- 全部组装。

每个零件说明书至少包含：

- 零件编码和系统分类；
- 位置和作用；
- 与其他零件的连接关系；
- 拆卸前提；
- 仿真拆卸顺序；
- 装回检查；
- 风险提示；
- 依据来源。

## 自动门禁

执行：

```bash
npm run appliance:check
```

检查内容：

- 参考实机是否登记；
- 是否启用逐件拆装；
- 零件 ID 和编码是否唯一；
- 说明书字段是否完整；
- 每个说明书零件是否在三维场景中存在；
- 系统分类是否覆盖关键子系统；
- 拆装模式下标是否有效。

完整验证仍使用：

```bash
npm run verify
```

## 安全边界

这些模型用于结构学习，不是维修教程。

空调实机涉及制冷剂压力、明火焊接、高低压电气、直流母线电容和环保法规。洗衣机实机涉及水、电、配重、弹簧储能、永磁转子吸力和重型筒体。实际维修必须使用具体型号的官方服务资料，并由具备相应能力的人员操作。
