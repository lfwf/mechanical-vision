# 内容制作与事实审查规范

## 1. 内容结构

每个实验至少覆盖：

- 定义和分类；
- 结构组成；
- 工作原理；
- 输入、处理和输出；
- 核心参数和公式；
- 参数变化影响；
- 适用场景；
- 优点和限制；
- 常见失效；
- 检查与维护认知；
- 常见误解；
- 适用范围和禁止用途。

## 2. 来源等级

- A：国际、国家、行业标准和正式规范；
- B：权威教材、专业手册和专业机构资料；
- C：制造商图纸、手册、样本和维护资料；
- D：同行评议论文、学术资料和专业会议资料；
- E：普通网站、博客、视频和论坛。

关键工程结论至少关联一个 A/B 级来源。E 级内容只能作为检索线索，不能单独支撑关键结论。

## 3. 关键结论登记

所有会影响用户判断的结论都必须在质量档案 `claims` 中登记，并关联 `sourceIds`。包括但不限于：

- 定义；
- 几何公式；
- 运动关系；
- 参数边界；
- 失效原因；
- 维护建议；
- 安全限制。

## 4. AI 使用边界

AI 可以：

- 检索候选资料；
- 整理术语；
- 生成内容草稿；
- 检查结构完整性；
- 发现来源之间的矛盾；
- 生成审核问题。

AI 不可以：

- 作为唯一事实来源；
- 自动批准内容；
- 在没有原始依据时补造参数；
- 把推测写成已证实事实；
- 省略适用范围和限制。

## 5. 表达要求

- 区分“理想关系”“典型情况”“标准要求”和“具体产品数据”；
- 公式必须解释符号、单位和适用条件；
- 不使用“绝对不会”“完全准确”等无法证明的表述；
- 维护和故障内容不得替代设备手册、企业规范和现场专业判断；
- 事实性内容修改必须提高内容版本号并重新审核。
