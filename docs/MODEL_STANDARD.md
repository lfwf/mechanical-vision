# 模型制作与审查规范

## 1. 双层资产

每个复杂模型应保留两套资产：

1. 工程母版：参数化 CAD、STEP、IGES、Parasolid、FreeCAD 源文件或可复现的程序化几何；
2. Web 展示模型：GLB/glTF 或 Three.js 运行时网格，用于加载、材质、动画和交互。

Web 模型不得成为唯一真实来源。任何减面、压缩和动画处理都必须能追溯到工程母版。

## 2. 模型卡必须记录

- 模型编号与版本；
- 精度等级；
- 单位和坐标系；
- 原始格式和 Web 格式；
- 建模方法；
- 关键参数；
- 适用用途；
- 禁止用途；
- 简化内容；
- 已知限制；
- 作者、审核人和日期。

## 3. 建模要求

### 几何

- 关键尺寸和比例必须来自标准、图纸或可信技术资料；
- 轴线、中心、基准面和运动副必须明确；
- 不允许未说明的零件穿透、悬空或错误装配；
- 程序化几何必须保留公式和参数来源；
- 复杂曲面应优先使用 CAD/几何内核验证，而不是只凭浏览器观察。

### 命名

复杂装配的零件名称统一采用：

```text
PART_<system>_<component>_<sequence>
```

示例：

```text
PART_pump_impeller_001
PART_pump_shaft_001
PART_pump_bearing_drive_001
```

### Web 优化

- 保留关键轮廓和接触面；
- 删除不影响教学的隐藏细节前必须记录简化理由；
- 使用 LOD 时，各级模型关键尺寸不能变化；
- 贴图、材质和颜色不得掩盖结构错误；
- 颜色应服务于部件区分和状态表达。

## 4. 运动模型要求

每个机构应定义不可破坏的机械不变量，例如：

- 齿轮：速度比、方向、中心距、相位和接触路径；
- 曲柄滑块：连杆长度不变、滑块只能沿导轨移动；
- 凸轮：从动件位移与设计运动规律一致；
- 行星齿轮：齿数关系、行星轮相位和 Willis 速度关系成立。

这些不变量应尽量写成自动检查。

## 5. 模型审核输出

模型审核人必须给出：

- 通过；
- 需修改；
- 拒绝。

审核结论必须写入质量档案，不能只在聊天或口头沟通中确认。
