# 机械视界质量政策

## 项目目标

机械视界不是 3D 素材陈列站。项目目标是用可验证的交互模型，帮助用户理解机械结构、运动关系、参数影响和工程边界。

任何模型都必须回答：

1. 它是什么；
2. 它由什么组成；
3. 运动和力如何传递；
4. 参数变化会发生什么；
5. 在什么条件下会失效或不再适用。

## 不可妥协的原则

- 不能把“外观看起来像”当成“几何正确”。
- 不能把“动画能转”当成“运动关系正确”。
- 不能把 AI 生成内容直接当成事实发布。
- 不能隐藏模型简化、适用范围和已知限制。
- 没有独立模型审核和内容审核，不得标记为正式发布。
- 无法确认的结论应删除、降级为假设或明确标记待核实。

## 精度等级

### L1 结构示意级

用于基础认识。部件关系基本正确，但不承诺精确尺寸和参数联动。

### L2 运动原理级

用于机构和运动学教学。关键几何比例、运动副、方向、速度关系和运动边界必须正确，不得出现未说明的穿透或脱离。

### L3 工程参数级

用于专业学习和方案比较。需要参数化几何、公式验证、边界检查、完整来源和独立专业审核。仍不能自动等同于制造或安全决策工具。

### L4 仿真与制造级

用于强度、寿命、制造或工程决策。必须包含材料、载荷、公差、接触、验证方法、适用标准和专业责任审核。没有相应能力时不进入该等级。

## 发布状态

- `draft`：选题或草稿；
- `research`：资料整理；
- `model-review`：模型审核；
- `content-review`：内容审核；
- `integration-review`：网页集成验证；
- `preview`：可公开试用，但存在明确阻断项；
- `released`：发布门禁全部通过；
- `rejected`：模型或内容不满足要求，停止发布。

## 最低发布要求

正式发布必须同时满足：

- 模型卡完整；
- 内容卡完整；
- 至少一个 A/B 级来源；
- 所有关键结论可追溯到来源；
- 所有关键验证项通过；
- 独立模型审核通过；
- 独立内容审核通过；
- 集成审核通过；
- 自动质量门禁通过。
