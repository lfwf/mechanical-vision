# v0.4 交互模型精度优化与空调实验设计

## 目标

本轮不是继续堆叠模型，而是解决五个已暴露的交互与几何问题，并建立更适合系统设备的表达方式。

核心原则：

1. 镜头操作必须连续、可控，不能因滚轮设备差异发生跳跃。
2. 机构零件必须分清运动平面、轴向层和固定/移动边界。
3. 动画必须让用户看懂输入、能量传递、输出和限制，而不是只让模型“动起来”。
4. 拆解必须沿维护或装配方向展开，不能把零件随机炸开。
5. 不具备定量能力的模型明确保持 L1/L2 预览级，不伪装成工程仿真。

## 通用镜头设计

原 OrbitControls 直接处理滚轮，不同鼠标和触控板的 `deltaY` 差异很大，容易一步过近或过远。

新方案：

- 拦截滚轮输入并归一化；
- 使用指数比例修改“目标距离”；
- 每帧阻尼逼近目标距离；
- 每个实验单独设置合理的最小和最大距离；
- 旋转、平移和相机复位继续由 OrbitControls 管理。

验收：连续滚动时模型尺寸平滑变化，不出现瞬间贴脸或缩成小点。

## 曲柄滑块

问题根因：曲柄盘、曲柄销、连杆和滑块销位于同一轴向层，视觉上相互覆盖。

优化：

- 用轮毂、曲柄臂和配重替代完整圆饼；
- 曲柄臂位于低轴向层；
- 连杆和两端环位于更高轴向层；
- 销轴跨层连接，但不让连杆实体切入曲柄臂；
- 滑块和导轨保留独立间隙。

## 偏心圆盘凸轮

问题根因：弹簧被固定在从动件组内，无法随升程正确改变长度；固定导向、圆盘和弹簧缺少明确空间层级。

优化：

- 滚子位置由偏心圆接触方程实时计算；
- 导杆长度随滚子位置变化；
- 弹簧上端固定、下端随从动件移动，实时压缩和伸长；
- 导向由两侧固定导板表达，避开凸轮运动区域；
- 凸轮增加偏心标记，便于观察转轴与圆盘中心的差异。

## 单端面机械密封

原模型几何近似轴对称，即使旋转也难以从视觉上判断。

优化：

- 动环、轴和驱动套仍绕轴线旋转；
- 增加三个驱动凸耳和黄色相位标记；
- 增加轴上的长条见证标记；
- 静环、压盖和介质腔保持固定；
- 转速采用视觉限幅，低速可见、高速不过度闪烁。

## 单级端吸离心泵

原粒子路径缺少“入口—加能—扩压—出口”的分段表达。

新方案分成四步：

1. 蓝色粒子沿轴向进入叶轮眼；
2. 粒子在叶轮内由蓝/青转为橙色，表示叶轮对流体做功；
3. 橙色粒子进入透明蜗壳并沿周向汇集；
4. 红色粒子从切向出口排出。

新增“工作原理 / 结构拆解”两种模式。拆解模式沿入口、叶轮、蜗壳和出口的装配方向展开。粒子仍明确标记为概念路径，不是 CFD 结果。

## 分体式空调实验

### 三种模式

- 工作原理：显示风机、压缩机位置和四段制冷剂循环；
- 拆解观察：按维护方向展开室内机和室外机部件；
- 组合演示：用进度滑块把已展开部件逐步装回。

### 室内机层级

前面板 → 过滤网 → 蒸发器 → 贯流风机 → 排水与风道区域。

### 室外机层级

前护网 → 轴流风机 → 冷凝器 → 压缩机与管路区域。

### 制冷循环

压缩机 → 室外冷凝器 → 节流元件 → 室内蒸发器 → 压缩机。

颜色只表示流程阶段：

- 红：压缩机出口高温高压气体阶段；
- 橙：冷凝后高压液体阶段；
- 蓝：节流后低压低温混合物阶段；
- 青：蒸发后返回压缩机的低压蒸气阶段。

本模型不计算温度、压力、焓值、能效、制冷量和具体制冷剂状态，也不作为维修指导。
