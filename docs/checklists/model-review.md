# 模型审核清单

## 几何

- [ ] 单位、坐标系和基准明确
- [ ] 关键尺寸与来源一致
- [ ] 轴线、圆心和基准面正确
- [ ] 无未说明的穿透、破面和非流形几何
- [ ] 法线和表面方向正确
- [ ] 简化不改变教学结论

## 装配

- [ ] 零件相对位置正确
- [ ] 关键零件没有缺失
- [ ] 运动副和自由度正确
- [ ] 装配极限位置合理
- [ ] 动画没有脱离、跳变或错误约束

## 运动

- [ ] 速度和方向关系正确
- [ ] 相位和轨迹正确
- [ ] 参数极值下仍满足机械不变量
- [ ] 完整运动周期无未说明干涉
- [ ] 暂停、重置和参数切换不破坏状态

## Web 展示

- [ ] 关键结构在桌面和移动端可辨认
- [ ] 材质和光照没有掩盖几何问题
- [ ] 标签、剖视、透明和高亮含义一致
- [ ] 模型性能满足加载和交互要求

## 结论

- [ ] 通过
- [ ] 需修改
- [ ] 拒绝
