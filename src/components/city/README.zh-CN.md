# SENJER 动力之城

## 页面隔离

动力之城通过顶部主导航作为独立页签进入，不注册为机械实验，不使用实验目录、实验说明面板或通用实验参数 Store。

当前两个主入口：

- 机械实验室：保留原有实验目录和单项原理演示。
- SENJER 动力之城：独立大型场景、任务 UI、区域导航与城市状态。

## 第一阶段范围

已建立：

- 城市 UI 设计系统；
- 浮空岛和中央能源塔；
- 天空花园；
- 水路花园；
- 轨道、音乐和天文三个远景占位区；
- 桌面三栏布局；
- 底部区域导航；
- 任务步骤和实时参数；
- 昼夜切换、播放暂停；
- 基础移动端降级布局。

## 空间约束

- 城市主要区域使用固定世界坐标，不在组件内随机偏移；
- 运行结构与支撑结构保持父子关系；
- 风轮旋转中心与塔体分离，叶片包络不进入塔身；
- 天空花园升降台只沿 Y 轴运动，并限制在平台区域；
- 水体限制在独立池体圆柱范围；
- 相机禁止平移，并限制极角和距离，避免进入岛体或建筑内部。

## 后续拆分计划

随着功能扩展，将继续拆分：

```text
city/
├── core/
├── districts/
├── mechanisms/
├── environment/
├── camera/
├── gameplay/
├── ui/
└── debug/
```

第二阶段应优先增加统一相机预设、区域飞行导航、显式空间包围盒和开发调试层，再扩展交通、音乐和天文区域。
